**Hermes Assistant** is a personal, single-user automation that I (Phil Seguin)
run on my own hardware for my own use. It is not a product and has no other
users.

It accesses my own Google account data — Gmail (read-only) and Google
Calendar — solely to generate personal reminders, summaries, and calendar
suggestions that are delivered privately to me.

Data accessed through Google APIs is used only for those personal features, is
stored only on my own private server, is never sold, and is never shared with
any third party. Google user data is not used to train any machine-learning
model. Access can be revoked at any time from my Google Account security
settings.
